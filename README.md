# 🦆 PEW PEW — Duck Shooter

Play: **https://marccoandj-lab.github.io/pewpew/**

Free browser FPS with cartoon ducks, an AK, a sniper and egg grenades (explosive, flash and smoke eggs), with wallbangs.
CS-style Bomb Defusal on Mirage- and Dust II-style maps (the host picks the map in the lobby).
Serverless peer-to-peer multiplayer (WebRTC): create a room, send the invite link to a friend.

This repository only contains the built game (static files).
